# 搞磁盘 V1.00 交付与验证

日期：2026-10-18；版本 V1.00 / build 1；Bundle ID com.gaoseries.GaoCiPan。

## 功能与资料范围

用户本次明确要求制作并安装 App，覆盖需求文件的“不创建/安装 App”限制，其他研究、安全和真实介质边界继续适用。交付普通 NTFS 镜像只读分析、记录筛选、报告导出、独立设置和全部研究资料。没有真实磁盘访问、挂载、NTFS 写入、驱动、后台服务或小组件。

V1 不创建业务数据库，不自动留存分析历史和文件正文；设置只在会话内。安装前核查程序与全部已知本应用资料/偏好/容器及初始化记录，存在则备份并逐文件核验，不可读/缺失已初始化资料则停止。任何已有资料均保留原路径；无数据格式迁移，不修改钥匙串。不读取或清理其他独立应用的数据。

## 验证方式

- Swift 6、Apple Silicon、macOS 14 部署目标，warnings-as-errors 类型检查。
- 原创合成 NTFS 结构及变异样本的有界解析断言；源文件前后 SHA-256 相同，不使用真实卷。
- 16 项导出定向测试：字节/权限核验、已有报告/镜像/链接保护、大小和路径预算、并发同名排他创建。
- 安装隔离测试覆盖初次安装、真实资料副本保留、旧程序压缩备份、失败恢复、初始化资料缺失/异常对象、恶意压缩包拒绝。
- 发行 ZIP 解压后逐文件摘要/模式与签名核验；实际安装脚本对 /Applications/搞磁盘.app 再次核验版本、签名和全部文件。每次安装均在私有长期备份目录生成受保护收据，不进入发行包。

按用户偏好未执行冒烟测试，未自动启动 App、浏览器、模拟器或测试窗口。真实 GUI、快捷键、文件选择/保存面板、权限撤销、Windows NTFS 实盘、OS/CPU 矩阵及热拔插/睡眠未验证。静态与隔离验证不称为全量实机业务通过。

## 签名、安装与清理

使用本机实际有效 Apple Development 身份；开发签名不是 Developer ID 公证。没有申请或冒充持有 FSKit entitlement，没有改变系统安全策略。

正式安装目标为 /Applications/搞磁盘.app。源码、资源、说明、测试、许可与最新版程序 ZIP/源码 ZIP/SHA-256 留在本项目；展开构建程序仅在 /private/tmp 临时目录，完成后删除。安装仅精确处理本 Bundle 的路径登记，不清空 LaunchServices，不改其他程序。源码与 Release 只包含程序和研究材料，不包含本机私有资料、备份、账户或凭据。

实际安装与线上发行的完成状态以最终交付消息及安装收据为准。研究结论是继续只读分析，暂缓真实磁盘写入；未来详细计划不作为本次继续写盘授权。
